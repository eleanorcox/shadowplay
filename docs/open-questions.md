# Open questions

Decisions that shape the plan. Roughly in order of how much they change it.

1. **Who is it for?** Children learning at home, families at an exhibition, or anyone? It decides how lessons are written, how forgiving recognition is, and whether it is a website or an installation.
2. **Hand points or silhouettes?** See [ideas](ideas.md). Proposed: start with hand points, because the aquarium already has them and they give precise hints, and add silhouettes if real shadows on a wall become the main way of using it.
3. **Screen first, or projector first?** A webcam and a screen are quickest to build and test. The projector with real shadows is the more magical end point.
4. **Which stack?** Proposed: **TypeScript in the browser with MediaPipe**, as in the aquarium, so it is shareable as a link and the hand tracking can be copied over.
5. **Which puppets first, and where do the lessons come from?** Who draws the hand diagrams and shadows? Eleanor, or found illustrations with a suitable licence?
